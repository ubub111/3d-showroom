# Форма · 3D-шоурум

Демонстрационный каталог изделий с 3D-конфигуратором. Исходное ТЗ лежит в [docs/3D_Showroom_TZ.md](docs/3D_Showroom_TZ.md).

## Запуск в Zed

Откройте папку проекта в Zed. Для запуска нужен Node.js 22.12 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для проверки производственной сборки используйте `npm run build`, затем `npm run preview`.

## Каталог

CSV-файлы в `data/` хранятся в UTF-8 с разделителем-запятой. Если исходные данные ведутся в XLSX, экспортируйте каждый из трёх листов в одноимённый CSV. Сборка преобразует таблицы в `src/catalog.json` и проверяет поля, уникальность ID и ссылки между записями.

- `categories.csv` задаёт категории. Оставьте `parent_id` пустым для раздела верхнего уровня или укажите ID родителя.
- `products.csv` задаёт товары, артикулы, цены и файлы моделей. Оставьте `model_url` пустым, чтобы показывать изображение-заглушку. Поле `store_url` включает кнопку перехода в магазин, если в нём задан адрес.
- `product_options.csv` задаёт значения опций. Первое значение группы выбирается по умолчанию. `modifier` меняет цену в рублях. `asset_url` подменяет модель целиком, поэтому для подмены модели используйте одну группу опций на товар. `color`, `metalness` и `roughness` применяются к материалу с именем из `material_name` (по умолчанию `Finish`).

Чтобы показать добавление категории, внесите в конец `categories.csv` новую строку:

```csv
souvenirs,,Сувениры,50,,Демонстрационный раздел
```

Перезапустите Vite или выполните новую сборку. Категория появится на главной и в фильтре каталога. Порядок задаёт `sort_order`. Изображения и модели размещаются в `public/`, а в таблицах указываются пути вида `/images/awards.webp` и `/models/facet.glb`. Для GLTF разместите вспомогательные файлы рядом с моделью.

Демонстрационные модели созданы из геометрии Three.js и сохранены в GLB. Чтобы пересоздать их, запустите `npm run models`. Обложки сгенерированы для демо. Для реальных изделий замените модели, изображения, цены и ссылки.

## Проверка

```bash
npx playwright install chromium
npm test
```

Для установленного Chromium можно указать путь к нему в переменной `SHOWROOM_CHROMIUM`.

## GitHub Pages

Подключите репозиторий GitHub и отправьте ветку `main`. В `Settings → Pages → Source` выберите `GitHub Actions`. Запустите workflow **GitHub Pages** вручную, если первый push был до включения Pages. Дальнейшие push в `main` обновляют опубликованный каталог. Vite использует относительные пути, а карточки открываются через hash-маршруты, поэтому ссылку на товар можно открыть напрямую.

Документация [GitHub Pages и GitHub Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
